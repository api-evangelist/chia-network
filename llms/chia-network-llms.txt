# Chia Network

> Chia Network builds an open-source, decentralized blockchain that uses a Proof of Space and Time consensus (farming on unused disk space instead of energy-intensive mining). The reference implementation (chia-blockchain) runs a full node, farmer, harvester, timelord, and wallet, and exposes a set of local, TLS-secured JSON RPC services plus the `chia` CLI and the Chialisp smart-contract language.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer surface; Chia does not publish its own llms.txt.

## APIs

- [Chia RPC API reference](https://docs.chia.net/rpc/): Local JSON-over-HTTPS RPC for full_node (8555), wallet (9256), farmer (8559), harvester (8560), datalayer (8562), crawler (8561), timelord (8557), solver (8667), and the daemon (55400) WebSocket router. Secured with TLS client certificates; ports are meant to stay on localhost.
